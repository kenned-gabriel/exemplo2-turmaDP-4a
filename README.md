## codigo em Linha e Blocos de Codigo 
use uma crase para destacar um
comando ou trech curto no meio de 
uma frase.

O comando `git status` mostra o
estado atual do repositorio.

o comando `git add .` adiciona os 
arquivos  modificados à *staging 
area*.

o comando `git commit -m "Texto com a descrição do que foi feito"` registra as alterações com uma mensagem.

o comando `git push origin main`
sobe as alterações para nuvem.

```
git status 
git add . 
git commit -m "Texto com a descrição do que foi implementado"
git push origin main
```
